```
> gh auth login, 너무 번잡스러워, 간단하게 로그인 되도록, gh-auth-login.sh 스크립트 만들어줘.
```

```bash
rtutor@virtual-mac1 claude-playground % ls
gh-auth-login.sh install-claude.sh install-gh.sh

# github 로그인
rtutor@virtual-mac1 claude-playground % ./gh-auth-login.sh
==> github.com 에 브라우저로 로그인
...
```

```
❯ gh repo create my-project --private/--public, 해당 명령어가 번거로워. 간단히 저장소 생성하는 gh-repo-create.sh 스크립트 작성해줘. 이름과 --private/--public만 필수야.
```

```bash
rtutor@virtual-mac1 claude-playground % ls
gh-auth-login.sh gh-repo-create.sh install-claude.sh install-gh.sh

# github 원격저장소 생성
rtutor@virtual-mac1 claude-playground % ./gh-repo-create.sh claude-playground --public

...
```
